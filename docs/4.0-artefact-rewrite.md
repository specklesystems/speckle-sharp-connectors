# Speckle 4.0 — Connector Artefact Rewrite

> **Status:** in progress. This document is the source of truth for migrating each connector onto the
> Speckle 4.0 client-side artefact pipeline. Read it before starting work on a new connector.

## The mandate (read this first)

Speckle 4.0 moves model serialization **off the server**. The client no longer builds an in-memory
`Base`/`Collection` graph and sends it through `ISendOperation` for the server to serialize; instead the
**client writes three passive Zstd-Parquet artefacts directly**, and the server just stores them on S3.
Receive is the inverse: the client **downloads the parquet artefacts and bakes them straight into the host
app**.

This is a **rewrite, not an adaptation**. The hard rules:

1. **Every _sender_ connector introduces a new `IArtifactRootObjectBuilder<THostObject>`.** It extracts geometry +
   topology from the host document and writes the parquet artefacts directly. It does **not** assemble a
   `Collection`/`DataObject`/proxy graph.
2. **Every _receiver_ connector introduces a new `IArtifactHostObjectBuilder`.** It reads the parsed
   `ArtefactBundle` (neutral dense-int graph + raw geometry blobs) and creates **native** host objects, layers,
   materials and instances directly. It does **not** reconstruct a `Base` graph or run the v1 traversal /
   `RootObjectUnpacker` / per-type converters.
3. **The old `Base`-oriented classes must not be used** anywhere on the 4.0 path: no `DataObject`, `Collection`,
   `RenderMaterialProxy`, `InstanceProxy`, `InstanceDefinitionProxy`, `RawEncoding`-as-carrier, no
   `DefaultTraversal`. Geometry is produced into / read from SGEO + raw blobs and converted directly to/from
   native host geometry and its topology (layers, levels, materials, instances, containers).
4. **The v1 path stays only as a legacy fallback** for receiving old (non-4.0) versions. Do not grow new code on
   it. New connector code targets the artefact path exclusively.
5. **Refactor shared converters/decoders as needed** to keep the artefact path Base-free (e.g. add `byte[]`
   overloads, add neutral decode paths) rather than reusing the Base-producing ones.

If something forces a `Base` (e.g. the conversion-report `ReceiveConversionResult.source` requires one), use a
**plain `Base`** with `applicationId`/`id` set — never a custom subclass (the `TypeLoader` only accepts
assembly-scanned registered types) and never the rich v1 types.

## The artefact model

A version's bundle is a directory of parquet files, base-named by the (server-pre-allocated) `versionId`:

| File | Purpose |
|---|---|
| `{v}.geometries.parquet` | Opaque **SGEO** geometry blobs + raw encodings (e.g. 3dm), keyed by dense int `geometryIndex`. Can be sharded (`.geometries.{n}.parquet`). |
| `{v}.eav.objects.parquet` | `object_index` ↔ `application_id` (object identity = host appId). |
| `{v}.eav.paths.parquet` | property path dictionary (`path_index` → dotted path). |
| `{v}.eav.eav.parquet` | flattened per-object property rows (`object_index`, `path_index`, `value_string/double/boolean`). |
| `{v}.eav.types.parquet` / `type_eav` / `object_type` | type dictionary + per-type property rows + object→type. |
| `{v}.envelope.nodes.parquet` | graph **nodes** (`id`, `kind`, `name`, `def_ref`, `transform`, `units`, `argb`, `opacity`, …). |
| `{v}.envelope.relations.parquet` | graph **relations** (`rel`, `src`, `dst`, `ord`). |
| `{v}.envelope.scene_views.parquet` | grouping/explorer hierarchies (`view`, `name`, `is_default`, `ord`, `source`, `ref`). |
| `{v}.envelope.{meta,node_kinds,rel_types}.parquet` | self-describing vocab + schema version. |

### Three dense-int namespaces
- **object** = `eav.object_index` = relation `src` for object-rooted relations.
- **geometry** = `geometryIndex` = `dst` of DISPLAY/SOLID/DEFINES, `src` of HAS_MATERIAL/HAS_COLOR.
- **node** = `envelope.nodes.id` = `dst` of IN_COLLECTION/IN_MODEL/ON_LEVEL/DISPLAY_INSTANCE/HAS_MATERIAL/…

### Relation vocab (`RelKind`, see `Speckle.Sdk/Pipelines/Send/Artifacts/EnvelopeWriter.cs`)
`1 DISPLAY` (obj→geom), `2 SOLID` (obj→geom, raw 3dm), `3 SUBELEMENT` (obj→obj), `4 DEFINES` (node→geom),
`5 HAS_MATERIAL` (geom→node), `6 HAS_COLOR`, `7 ON_LEVEL` (obj→node), `8 DISPLAY_INSTANCE` (obj→node),
`9 DEFINES_INSTANCE` (node→node), `10 IN_COLLECTION` (obj→node), `11 IN_MODEL` (obj→node), `12 IN_ROOM` …
`20 XREF`, `21 CONNECTS_TO`, `22 HOSTED_ON`.

### Node vocab (`NodeKind`)
`1 DEFINITION`, `2 INSTANCE`, `3 MATERIAL`, `4 COLOR`, `5 LEVEL`, `6 COLLECTION`, `7 CONTAINER`.

### Scene views (the explorer / layer hierarchy)
Each row is one grouping **tier** of a view, ordered by `ord`. `source`:
- `"rel"` → group by a relation's target node; `ref` = the `RelKind` number (e.g. `11`=IN_MODEL container,
  `7`=ON_LEVEL, `10`=IN_COLLECTION).
- `"eav"` → group by an object property; `ref` = the property path (e.g. `category`, `family`).

The **default** view (`is_default=true`) drives the received layer hierarchy. Examples observed:
- **Revit:** `11 > 7 > category > family` → **Model → Level → Category → Family**.
- **Rhino:** `[10]` → a single IN_COLLECTION tier (its nested collection tree is ancestry-walked).

> **Instancing differs by host.** Rhino definitions reference geometry that is *also* an object's DISPLAY
> (member objects exist). Revit definitions own their geometry **directly and standalone** (`DEFINES`→geometry,
> no member objects), and an object may place **many** instances (railing→balusters). A correct receiver builds
> instance definitions from `DEFINES`→geometry and places one instance **per `DISPLAY_INSTANCE` edge**.

## SDK building blocks (consume; do not duplicate)

Repo `speckle-sharp-sdk`. All artefact code is guarded `#if NETSTANDARD2_0 || NET8_0_OR_GREATER` so the
netstandard2.0 build is available to net48 connectors.

### Send (write artefacts)
- `Speckle.Objects/Utils/ObjectsArtifactPipeline.cs` — the producer façade. Key calls: `InternObject(appId)`,
  `AddProperties(...)`, `AddGeometry(meshAppId, Base)→geometryK` (SGEO-encodes + dedups), `AddDefinition`,
  `AddInstance(transform,units)`, `AddMaterial(argb,opacity,…)`, `AddLevel`, `AddContainer(key,name,parent,"Model")`,
  relation helpers (`Display`, `Solid`, `DisplayInstance`, `Defines`, `HasMaterial`, `OnLevel`, `InModel`, …),
  `AddSceneView(SceneView)`, `Complete()`.
- `Speckle.Objects/Utils/SgeoEncoder.cs` — `Encode(Base)` → SGEO blob (11 primitive types).
- `Speckle.Sdk/Pipelines/Send/Artifacts/ArtifactPipeline.cs` — upload: `ArtifactPipelineFactory.CreateInstance(...)`
  then `UploadFilesAsync(bundle, rootId, totalChildren)` (sign → presigned PUT per file → complete).

### Receive (read artefacts) — **the Base-free path**
- `Speckle.Sdk/Pipelines/Receive/Artifacts/ArtefactBundle.cs` — **the neutral parse**.
  `ArtefactBundleReader.ReadAsync(dir)` → `ArtefactBundle` (host-agnostic): `Geometries` (index→`ArtefactGeometry{Content,Type,IsSgeo}`),
  `ObjectAppIds`, `Properties` (nested dict), `Nodes` (`ArtefactNode`), `Relations` (`ArtefactRelations`),
  `Units`, `DefaultSceneView` (`IReadOnlyList<SceneViewTier>`). `ArtefactRelations` exposes grouped lookups:
  `Display`, `SolidByObject`, `MaterialByGeometry`, `DefinesByDefinition`, `DisplayInstanceEdges`,
  `ObjectNodeByRel` (rel→object→node, for scene-view tiers), `ObjectByGeometry()`.
- `Speckle.Objects/Utils/SgeoDecoder.cs` — `TryDecodeMesh(bytes, out SgeoMesh)` is the **Base-free** mesh decode
  (flat verts/faces/colors/units); top-level `SgeoMesh` record. (`Decode(bytes)→Base` still exists for the v1
  fallback only.)
- `Speckle.Sdk/Pipelines/Receive/Artifacts/ArtifactDownloader.cs` — `DownloadBundleAsync(account,p,m,v,dir)` →
  GETs `/api/v2/projects/{p}/models/{m}/versions/{v}/artifacts` → presigned downloads. Empty list ⇒ no 4.0 bundle.
- `Speckle.Objects/Utils/ObjectsArtifactReader.cs` — maps a bundle → a v1 `Base` graph. **Legacy/fallback only**
  (used by connectors that have not yet got a native `IArtifactHostObjectBuilder`, e.g. Revit receive today). New
  connectors must NOT use this.

## Connector contracts

### Send: `IArtifactRootObjectBuilder<THostObject>`
`Sdk/Speckle.Connectors.Common/Builders/IArtifactRootObjectBuilder.cs`. Drops into the existing
`RunOnMainAsync`+`gatherObjects` flow like the v1 `IRootObjectBuilder<T>`. Drives `ObjectsArtifactPipeline` and
owns write+upload; returns a minimal `version="4"` shell so `SendOperation` does not re-serialize. Branch in
`Sdk/Speckle.Connectors.Common/Operations/SendOperation.cs` (`SendViaArtifacts`).

### Receive: `IArtifactHostObjectBuilder`
`Sdk/Speckle.Connectors.Common/Builders/IArtifactHostObjectBuilder.cs`:
```csharp
Task<HostObjectBuilderResult> Build(ArtefactBundle bundle, string projectName, string modelName,
    IProgress<CardProgress> onOperationProgressed, CancellationToken cancellationToken);
```
- `IArtifactReceiver` (`Sdk/.../Operations/ArtifactReceiver.cs`) downloads+parses → `ArtefactBundle?`
  (`TryGetBundleAsync`); `Reconstruct(bundle)` is the legacy Base mapping for connectors without a native builder.
- `ReceiveOperation.Execute` branches: a bundle is present **and** an `IArtifactHostObjectBuilder` is registered →
  **direct native bake**; else reconstruct → v1 host builder; else (no bundle) → v1 deserialize.
- Register `IArtifactHostObjectBuilder → <YourConnector>HostObjectArtefactBuilder` in the connector's DI to
  activate the native path.

## Recipe: migrating a new connector

**Send:**
1. Add `Connectors/<Host>/.../Operations/Send/<Host>ArtifactRootObjectBuilder.cs : IArtifactRootObjectBuilder<THost>`.
2. Per source document → `AddContainer(...,"Model")`; per element → `InternObject` + `AddProperties` + geometry
   (`AddGeometry`+`Display`, or solids→raw + `Solid`; instances→`AddDefinition`/`AddInstance`+`DisplayInstance`).
3. Post-loop value nodes: materials→`AddMaterial`+`HasMaterial`, levels→`AddLevel`+`OnLevel`, defs→`AddDefinition`+`Defines`.
4. `AddSceneView(...)` with the host's natural hierarchy (e.g. Level/Category/Family). `Complete()` → glob → `UploadFilesAsync`.
5. Register the builder + `IArtifactPipelineFactory` in DI; flip registration once validated.

**Receive:**
1. Add `Connectors/<Host>/.../Operations/Receive/<Host>HostObjectArtefactBuilder.cs : IArtifactHostObjectBuilder`.
2. Build layers from `bundle.DefaultSceneView` (resolve `rel` tiers via `Relations.ObjectNodeByRel` + node
   ancestry; `eav` tiers via `Properties`). Create native layers/levels.
3. Materials from MATERIAL nodes → native materials; map object & geometry → material via HAS_MATERIAL.
4. Atomic objects: decode their DISPLAY/SOLID geometry (`SgeoDecoder.TryDecodeMesh` / raw decode) → **native
   geometry**, bake onto the scene-view layer with material.
5. Instances: build native definitions from `DEFINES`→geometry; place one per `DISPLAY_INSTANCE` edge with the
   instance node transform (apply units).
6. Skip non-geometric elements silently (no error). Use a plain `Base` only for `ReceiveConversionResult.source`.
7. Register `IArtifactHostObjectBuilder` in DI.
8. **Diagnostics:** write a verbose receive log (counts + failure categories) to a temp file so runs can be
   diagnosed offline (the connector `ILogger` only reaches Seq). Rhino writes
   `%TEMP%\Speckle\rhino-artefact-receive.log`.

> **Tip:** bundles for a received version land in `%TEMP%\speckle\receive\{versionId}\`. You can analyse them
> offline (DuckDB/Python over the parquet) to understand a model's topology before/while debugging a builder.

## Build & environment gotchas

- **.NET SDK:** build with the user-local SDK `C:\Users\oguzh\.dotnet\dotnet.exe` (10.x). The `dotnet` on PATH is
  .NET 7/8 only and cannot build the net10 TFMs. Rhino/GH plugins are **net48** (`.NET 7 is not an option`).
- **Config:** connectors reference the **local** `speckle-sharp-sdk` in `-c Local`.
- **Lock files:** the repos set `ContinuousIntegrationBuild=true` + `RestorePackagesWithLockFile=true` ⇒
  **locked-mode** restore. After cleaning `obj/bin` or changing deps a restore fast-fails with a misleading
  `NU1101: System.Memory` (NOT an offline/feed issue). Fix: `dotnet restore <proj> -p:Configuration=Local
  --force-evaluate`, then `build … --no-restore`.
- **ILRepack:** `Speckle.Sdk.Dependencies` and `Speckle.Connectors.Logging` are ILRepacked. Incremental builds
  double-merge internalized types → `BadImageFormatException: Duplicate type …` at plugin load. Fix: clear their
  `obj/bin`, `--force-evaluate` restore, rebuild clean.
- **File locks:** close the host app (Rhino/Revit) before rebuilding — it locks the plugin DLLs (`MSB3027`).
- **Shared projects:** files under `Speckle.Connectors.RhinoShared` (a `.shproj`/`.projitems`) must be added to
  `Speckle.Connectors.RhinoShared.projitems` — they are not auto-globbed.
- **TypeLoader:** any `Base` you instantiate on the receive path must be a plain registered `Base`, not a custom
  subclass, or `TypeLoader` rejects it.
